# Массовая испытательная кампания

Кампания нужна, когда требуется прогнать агент 1 на множестве характеристик проектов и найти устойчивые классы отказов.

## Создание набора

После `context_preflight` создай новый каталог внутри возвращённого `output_dir` или внутри репозитория, но вне `data/`. Это позволит использовать полученные IR на MPP-ступени. Не используй существующее имя:

```powershell
python .agents/skills/grp-agent-tester/scripts/campaign.py create <новый-каталог> --count 36 --include-invalid
```

Генератор использует фиксированный seed и сохраняет `manifest.json`. Валидные случаи варьируют число и этажность корпусов, подземные этажи, фасад, покорпусное остекление, паркинг, ограждение котлована, типы свай, долю отделки и индивидуальные условия. Невалидные случаи по одному нарушают обязательные группы входного контракта.

## Локальный прогон Excel/IR

```powershell
python .agents/skills/grp-agent-tester/scripts/campaign.py run <каталог-кампании>
```

Каждый запуск создаёт новый каталог `runs/<timestamp>`. Для каждого случая сохраняются консольные журналы, Excel и IR при успешном построении. Итоги записываются в `results.json` и `report.md`. Существующие результаты не перезаписываются.

Считай валидный случай успешным только при коде 0 у построения и Excel-валидации. Невалидный случай успешен как тест только когда агент отклонил его управляемо, без traceback.

## MPP-ступень

Не экспортируй десятки MPP без необходимости. Выбери стратифицированную выборку минимум из одного и двух корпусов, граничных подземных этажей, всех фасадов и остеклений, без свай и с двумя типами свай, а также хотя бы одного ранее падавшего случая.

Для каждого выбранного успешного IR вызови `mpp_export` в новый файл, затем `mpp_validate` с тем же IR и новым JSON-отчётом. Любая ошибка MPP блокирует приёмку соответствующего случая.

## Анализ отказов

Группируй результаты по комбинации характеристик, а не только по сообщению. Найди минимальный воспроизводящий вход для каждого класса отказа. Отдельно отмечай ошибки входного контракта, traceback, нарушения IR/DEC-40, ложный зелёный результат Excel, расхождения MPP↔IR и нестабильность повторных запусков одинакового seed.

Не исправляй вход так, чтобы скрыть отказ. Сохраняй исходный JSON и связывай его с записью результата.
