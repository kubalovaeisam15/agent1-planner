# MS Project Agent — переносимый комплект

Этот комплект создаёт и проверяет корпоративные графики ГРП через Codex или
Claude Code. Оба клиента используют одни предметные инструкции и один локальный
MCP-сервер. MPP создаётся на базе `data/Шаблон ГРП.mpp`.

## Что требуется на новом ПК

- Windows 10/11;
- Microsoft Project Desktop;
- Python 3.12 или совместимый Python 3;
- Codex и/или Claude Code;
- доступ пользователя к этой папке на чтение и запись.

Рекомендуется распаковать комплект в локальную папку без синхронизации OneDrive,
например `D:\Agents\MS-Project-Agent`.

## Установка

Откройте PowerShell в корне распакованной папки и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup\install.ps1
```

Установщик проверит Python, Microsoft Project, корпоративный шаблон и инструкции,
а затем создаст локальные конфигурации:

- `.codex/config.toml` — для Codex;
- `.mcp.json` — для Claude Code.

После установки перезапустите Codex. В Codex откройте эту папку как локальный
проект. Для Claude Code перейдите в корень папки и выполните `claude`.

## Первая проверка

Попросите агента:

> Проверь готовность MS Project Agent. Покажи версии инструкций, наличие
> корпоративного шаблона и список доступных MCP-инструментов. Файлы не изменяй.

Затем можно выполнить тестовый расчёт на `tests/etalon_project.json`, обязательно
задав новые имена выходных файлов.

## Обычный запрос

> Построй ГРП по ТЭП `<путь к JSON>`. Сначала проверь обязательные параметры.
> Создай Excel, Schedule IR и новый MPP на базе корпоративного шаблона. Не
> перезаписывай существующие файлы. После экспорта выполни полную валидацию.

Сначала проверяйте лист «Допущения» и карты вех, затем критический путь и MPP.
Корректировки задавайте через исходные параметры или правила, а не ручным
переносом итоговых дат.

## Важные ограничения

- исходный `data/Шаблон ГРП.mpp` не редактировать;
- результаты сохранять под новыми версиями в `out`;
- не переносить в комплект API-ключи, токены и пользовательские учётные данные;
- прямое создание MPP требует локально установленного Microsoft Project;
- история диалогов не является частью агента: правила находятся в `AGENTS.md`,
  `CLAUDE.md` и каталоге `instructions`.

Повторная проверка без изменения конфигурации:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup\install.ps1 -CheckOnly
```
