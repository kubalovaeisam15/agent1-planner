# MS Project Agent — краткая инструкция

Комплект предназначен для создания и проверки корпоративных графиков ГРП
через Codex или Claude Code. MPP формируется на базе корпоративного файла
`data/Шаблон ГРП.mpp`.

## Требования

- Windows 10/11;
- Microsoft Project Desktop;
- Python 3.12 или совместимый Python 3;
- Codex и/или Claude Code.

Распакуйте архив в локальную папку, например:

```text
D:\Agents\MS-Project-Agent
```

Не рекомендуется работать с активным MPP непосредственно из синхронизируемой
папки OneDrive.

## Установка

Откройте PowerShell в корне распакованной папки и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup\install.ps1
```

Установщик проверит Python, Microsoft Project и обязательные файлы, после чего
создаст конфигурации `.codex/config.toml` и `.mcp.json` для этого компьютера.

После установки:

- перезапустите Codex и откройте распакованную папку как локальный проект;
- либо запустите `claude` из корня папки для работы через Claude Code.

## Первая проверка

Отправьте агенту запрос:

> Проверь готовность MS Project Agent. Покажи версии инструкций, наличие
> корпоративного шаблона и доступные MCP-инструменты. Файлы не изменяй.

## Создание графика

Пример рабочего запроса:

> Построй ГРП по ТЭП `<путь к JSON>`. Сначала проверь обязательные параметры.
> Создай Excel, Schedule IR и новый MPP на базе корпоративного шаблона. Не
> перезаписывай существующие файлы. После экспорта выполни полную валидацию.

Сначала проверяйте лист «Допущения» и карты вех, затем критический путь и MPP.
Изменения задавайте через ТЭП и правила планирования, а не ручным переносом
итоговых дат в Microsoft Project.

## Важно

- не редактируйте исходный `data/Шаблон ГРП.mpp`;
- каждую итерацию сохраняйте под новым номером версии;
- не помещайте в папку API-ключи, токены и пароли;
- для создания MPP Microsoft Project должен быть установлен локально;
- результаты рекомендуется сохранять в `out`;
- корпоративный шаблон требует защищённого способа передачи архива.

Проверить окружение повторно без изменения конфигурации:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup\install.ps1 -CheckOnly
```
