# Проверка агента 1

Запусти существующий набор тестов без изменения файлов. Отдельно оцени:

- соответствие hook, манифеста и маркеров версий;
- негативные тесты DEC-34…41;
- одинаковость инвариантов Excel-, IR- и MPP-валидаторов;
- путь ТЭП → Excel/IR → MPP → повторное открытие → сверка;
- запрет перезаписи шаблона и существующих результатов;
- наличие версий и SHA256 входов в отчёте.

Пропущенный тест — непроверенная ветка, не успех. При проверке исправления сначала воспроизведи исходный отказ, затем запусти узкий тест и регрессию. Не меняй эталон под результат.
