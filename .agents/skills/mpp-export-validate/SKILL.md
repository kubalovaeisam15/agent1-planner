# Экспорт и проверка MPP

1. Если в текущей задаче ещё нет успешного результата, вызови `context_preflight`.
2. Вызови `mpp_export` без `mpp_path` для нового имени в папке выдачи либо с новым путём внутри `output_dir` из preflight; `template_path: data/Шаблон ГРП.mpp`. Экспорт сам проверяет IR.
3. Обязательно вызови `mpp_validate` с тем же IR и новым JSON-отчётом в `output_dir`.
4. Готов только MPP без ошибок; предупреждения перечисли отдельно.

Никогда не изменяй шаблон и не перезаписывай файлы. При зависании Project не запускай параллельный экспорт: дождись таймаута, устрани открытый диалог и повтори под новым именем.

Сообщи пути к MPP и отчёту, использованный шаблон, количество задач, связей, ошибок и предупреждений.
