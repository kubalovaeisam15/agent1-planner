# Построение ГРП

## Перед расчётом

1. Полностью прочитай `instructions/typGRP.md`, `instructions/bindings.md` и `instructions/standards.md`.
2. Сверь версии с таблицей в `AGENTS.md`. При несовпадении останови расчёт и сообщи расхождение.
3. Проверь пять блокирующих групп входа из `AGENTS.md` §2.1. Если данных не хватает, запроси весь закрытый список одним сообщением.
4. Не используй `instructions/Шаблон_ГРП v2.xlsx`, калибровочные графики или собственный опыт как источник нормативов.
5. При конфликте чисел следуй протоколу `AGENTS.md` §0.2 и правилу «нет молчаливого выбора» §0.3.

## Выполнение

1. Приведи ТЭП к JSON-контракту `tests/project.template.json`, не выдумывая отсутствующие значения.
2. Для необязательных пробелов примени только явно разрешённые умолчания и занеси их в «Допущения».
3. Вызови MCP-инструмент `schedule_build`, задав новые пути для `.xlsx` и Schedule IR `.json`, предпочтительно в `out/`.
4. Вызови `schedule_validate_ir` для созданного IR. Ошибки устрани в данных или правилах; не правь рассчитанные даты вручную.
5. Проверь наличие всех обязательных листов, открытых вопросов, применённых `DEC-*`/`R-*` и строк с обязательным раскрытием допущений.

## Результат

Сообщи пути к Excel и IR, число задач и связей, даты начала/окончания, результат проверки, ключевые допущения и открытые вопросы. Не называй график готовым к утверждению: окончательное решение принимает планировщик проектного офиса.

Если нужен MPP, продолжи по skill `mpp-export-validate`.
