# Аудит графика ГРП

Работай только на чтение. Если в текущей задаче ещё нет успешного результата, вызови `context_preflight`.

- IR: вызови `schedule_validate_ir`; его ответ уже содержит сводку.
- MPP: вызови `mpp_validate`, обязательно с IR при его наличии. Без IR отметь ограничение структурной проверки.
- Excel: используй `tools/validate_grp.py`, проверь обязательные листы, карты вех, «Обоснование» и «Допущения».

Полные нормативы не загружай заранее. Для каждой найденной проблемы открой только процитированный раздел `typGRP.md`, `bindings.md`, `standards.md`, `instructions/agent-policy-full.md` или конкретный код в `РАСХОЖДЕНИЯ_шаблон_v2.md`.

Начни с «годен / годен с замечаниями / не годен». Раздели ошибки, предупреждения и открытые условия; укажи задачу, факт, требование и источник. Предложи минимальное исправление, но не выполняй его без запроса.
