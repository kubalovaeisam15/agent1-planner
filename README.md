# Агент 1. Планировщик графика

Рабочая среда агента «Планировщик графика» системы «ИИ-проектный офис» (Level Group).
Пилот — Level Гребной, Этап 1 (выдача в Excel по шаблону ГРП).

## Состав

```
CLAUDE.md                      контракт агента: процесс, выдача, чек-лист §9, границы
instructions/
  typGRP.md                    структура WBS, коды задач, вехи, регламентные сроки фазы A
  bindings.md                  привязки СМР, якоря, лаги, тепловой контур, сезонность
  standards.md                 числовые нормативы длительностей и умолчания
  Шаблон_ГРП.xlsx              эталон структуры: 1 545 задач (1 корпус + 1 паркинг)
tests/
  etalon_TEP.md                вход регрессионного прогона
  etalon_expected.md           ожидаемый результат и допуски
  template_parsed.json         машинный разбор эталона (генерируется)
tools/
  parse_template.py            разбор шаблона + сверка статистики typGRP.md §3
  validate_grp.py              валидатор выдачи по машинной части чек-листа §9
  inspect_template.py          разведка структуры xlsx
```

Версии комплекта сверяются между файлами: `CLAUDE.md` v5.1 · `typGRP.md` v2.2 · `bindings.md` v1.3 · `standards.md` v1.2. При расхождении версий агент обязан остановиться (`CLAUDE.md` §0).

## Требования

- Python 3.12+, `openpyxl` (`pip install openpyxl`)
- Git

## Команды

```powershell
# разбор эталона и сверка со статистикой typGRP.md §3
python tools\parse_template.py

# валидация выдачи агента
python tools\validate_grp.py out\ГРП_проект.xlsx

# самопроверка валидатора на эталоне
python tools\validate_grp.py tests\template_parsed.json
```

## Регрессионный прогон

1. Подать агенту содержимое `tests/etalon_TEP.md` §1 как ТЭП.
2. Получить ГРП.
3. Прогнать `tools/validate_grp.py` — машинная часть чек-листа §9.
4. Сверить с `tests/etalon_expected.md` §1: РС 02.04.2024 ±14 дн, РВЭ 22.06.2026 ±14 дн, фаза A 447 дн, фаза РС→РВЭ 811 дн.

При отклонении разбирается причина в `standards.md` / `bindings.md` / входных данных. **Правка `etalon_expected.md` «под результат» запрещена.**

### Самопроверка валидатора на эталоне даёт 3 ошибки — это норма

Шаблон не является выдачей агента. Ошибки воспроизводят задокументированные расхождения `typGRP.md` §13:

| Ошибка | Расхождение |
| --- | --- |
| 370 суммарных строк с собственными данными | норма для шаблона; в выдаче запрещено (§2.2 п.4) |
| 12 разрывов в столбце `Ид.` | §13 расх. 9 |
| 3 связи на несуществующие `Ид.` | §13 расх. 10 |

Выдача агента обязана проходить валидатор **без ошибок**.
