# Экспорт и проверка MPP

## Обязательные условия

- Используй только `data/Шаблон ГРП.mpp` как базовый MPP.
- Никогда не изменяй и не перезаписывай корпоративный шаблон.
- Каждый результат сохраняй в новый `.mpp`, предпочтительно в `out/` с номером версии.
- Не закрывай и не сохраняй файл вручную через интерфейс Microsoft Project. Используй MCP-инструменты, которые управляют COM-процессом и таймаутом.

## Порядок

1. Вызови `schedule_validate_ir` и продолжай только при `valid: true`.
2. Вызови `mpp_export` с путём IR, новым путём результата и явным `template_path: data/Шаблон ГРП.mpp`.
3. После успешного экспорта обязательно вызови `mpp_validate` с тем же IR и новым путём JSON-отчёта.
4. Считай экспорт успешным только если отчёт не содержит ошибок. Предупреждения перечисли отдельно и не скрывай.
5. При зависании Microsoft Project не запускай второй параллельный экспорт. Дождись таймаута, проверь открытые диалоги Project и только затем повторяй в новый файл.

## Результат

Сообщи пути к MPP и JSON-отчёту, имя использованного шаблона, число задач и связей, количество ошибок и предупреждений. Если валидация не пройдена, явно пометь MPP как непригодный для передачи.
